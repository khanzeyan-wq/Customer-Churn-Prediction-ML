# Customer Churn Prediction using Machine Learning

## Project Overview
This project predicts whether a telecom customer is likely to churn using supervised machine learning algorithms. The complete workflow includes data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, feature importance analysis, ROC curve comparison, and hyperparameter tuning.

## Dataset
- Dataset: Telco Customer Churn
- Records: 7,043
- Target Variable: Churn

## Machine Learning Pipeline
- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis (EDA)
- Feature Encoding
- Feature Scaling
- Train-Test Split
- Model Training
- Model Evaluation
- ROC Curve Comparison
- Feature Importance Analysis
- Hyperparameter Tuning

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- LightGBM

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC Score
- Confusion Matrix
